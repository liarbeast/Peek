Peek

Set up your Peek frame

This puts the Peek software on your frame, straight from this page. It takes about 5 minutes.

What you need

  • Your frame: the Seeed EE04 board with the 7.3" colour screen.
  • A USB-C cable that can carry data. The one from the kit works. Some phone chargers' cables only charge.
  • A computer with Chrome or Edge. Phones, Safari and Firefox can't do this.
  • Your Wi-Fi name and password. The frame only works with 2.4 GHz Wi-Fi, which almost every home router has.
  • Peek running on a computer or NAS in your home.

Install

  1. Plug the frame into this computer with the USB-C cable.

  2. Click Install. A list pops up: pick the frame (it's called something like "USB JTAG/serial debug unit") and click Connect. Then click Install Peek frame.

    This browser can't install the software. Open this page in Chrome or Edge on a computer.
    This page has to be opened over a secure (https) connection.

  3. Type your Wi-Fi name and password when the window asks for them, and click Connect.

  4. Done. Unplug the frame if you like. It finds Peek by itself and shows its first picture. The colours take about 30 seconds to appear.

Your Peek's address

If the frame says it can't find Peek, type this address on the frame's page.

Tips

  • Give Peek a fixed address. In your router, reserve the address of the computer or NAS that runs Peek. Routers call this "DHCP reservation" or "static lease". Then the frame always knows where Peek is.
  • Start Peek with its compose file. If you set up Peek by clicking through your NAS's Docker screen instead, tick use host network. Otherwise the frame can't find Peek by itself.
  • Peek in Docker Desktop on a Mac or Windows PC? The frame can't find Peek by itself there. Type Peek's address once on the frame's page (the frame's screen tells you how).

It didn't work

There's no Install button

Open this page in Chrome or Edge on a computer. Phones, Safari and Firefox can't install the software.

The frame isn't in the list

Press KEY0 on the board to wake the frame, then click Install again. Try another USB-C cable too: some only charge. Still nothing? Hold the small B button on the board, tap R, let go of B and click Install again.

The frame doesn't connect to Wi-Fi

Check the Wi-Fi name and password, and that your router has 2.4 GHz Wi-Fi switched on. Make sure the little antenna is clicked onto the board.

To try again: plug the frame in, click Install and choose Change Wi-Fi. Or, on your phone, join the Wi-Fi network Peek frame and pick your home Wi-Fi there.

The screen says it can't find Peek

Make sure Peek is running. Then, on a phone or computer on the same Wi-Fi, open the address the frame shows and type Peek's address, for example http://192.168.1.20:8080. Peek shows its own address in Settings, under Install firmware.

The frame is asleep and I want to change something

Press KEY0 on the board. The frame wakes up and stays awake for 5 minutes.
